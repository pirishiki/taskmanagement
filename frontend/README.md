# フロントエンド（React + TypeScript + Vite + Tailwind CSS）

タスクをボード画面（やるべきこと / 進行中 / 終わったこと の3列）に表示し、タスク名のキーワード・優先度・期限で絞り込んだり、各列の下のフォームからタスクを追加したりする画面。

## 必要なもの

- Node.js（LTS 版。npm も一緒に入る）

## 起動手順

DB とバックエンドを先に起動しておく（手順は [backend/構成表.md](../backend/構成表.md) を参照）。

| 順番 | 実行場所 | コマンド | 説明 |
| --- | --- | --- | --- |
| 1 | `frontend`フォルダ | `npm install` | 部品（ライブラリ）を取り寄せる（初回と、package.json が変わったときだけ） |
| 2 | `frontend`フォルダ | `npm run dev` | 開発用サーバーを起動する |
| 3 | ブラウザ | http://localhost:5173 を開く | ボード画面が表示される |

## API との通信

画面は `/api/tasks` を呼ぶ。開発用サーバー（Vite）のプロキシが、それをバックエンド（`http://localhost:8080`）に取り次ぐ（[vite.config.ts](vite.config.ts) の `server.proxy`）。
ブラウザから見ると同じアドレス（5173）とのやりとりになるので、バックエンド側で CORS の許可を設定する必要はない。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/main.tsx` | 入口。`index.html` の `#root` に `App` を表示する |
| `src/App.tsx` | 画面全体。列の一覧（`columns`。最初の表示時と、読み込みのあとに取り直す）と、タスク・読み込み中・エラー・検索の条件（`filters`。条件が1つでも選ばれていれば `isFiltering`＝検索・絞り込み中）の状態を持ち、検索・追加・編集（PUT）・完了（PATCH）・削除（DELETE）・並び替え（ドラッグ、および優先度順・期限が近い順の自動並び替え）・書き出し・読み込み・列の追加と削除を実行する。列の削除で、タスクが入っている列はサーバーが断る（409）ので、その理由を出して列は残す。読み込めたら列と、今の条件で一覧を取り直し、失敗したら何も変わっていないので取り直さない。並び替えは検索・絞り込み中もでき、先に画面を書き換えてから保存し、失敗したら今の条件で DB の状態を取り直す。ドラッグは、落とした位置のすぐ上のカードを伝えて `moveTask` を呼び、返ってきた番号で置き換える。自動並び替えは、見えているカードどうしで今の番号（席）を入れ替える（取り直しても、失敗のメッセージは消さない。メッセージを消すのは検索を始めたとき）。削除はサーバーで消せてから画面の一覧から外す。一覧の取得は、最後に頼んだものの結果だけを使う（検索を続けて押したとき、古い結果があとから届いて上書きしないように）。失敗したときは `errorMessage` で、失敗の種類ごとに違うメッセージを出す（つながらない／入力ミス（400。バックエンドが返した理由を添える）／見つからない（404。そのカードを一覧から外す）／今の状態ではできない（409。バックエンドが返した理由を添える）／サーバーのエラー（500）） |
| `src/types/column.ts` | API から返ってくる列の型 `BoardColumn`（id・name・sortOrder・fixed（基本の列か）・done（完了の列か）。バックエンドの `BoardColumnResponse.java` に対応） |
| `src/types/task.ts` | API から返ってくるタスクの型（バックエンドの `TaskResponse.java` に対応。どの列にいるかは `columnId`）、登録・編集（PUT）時に送る `NewTask` 型、一部だけ更新（PATCH）するときに送る `TaskPatch` 型、列の並び替えの基準（優先度順・期限が近い順）を表す `SortCriterion` 型、一覧の絞り込みの条件（キーワード・優先度のリスト・期限）を表す `TaskFilters` 型と、何も絞らない `noFilters` |
| `src/api/taskApi.ts` | API を呼ぶ関数（`fetchTasks`：一覧の取得。`TaskFilters` を `?keyword=…&priority=…&due=…` に変える（priority は選んだ数だけ `append`）、`createTask`：POST で登録、`updateTask`：PUT で丸ごと更新、`patchTask`：PATCH で一部だけ更新、`deleteTask`：DELETE で削除、`moveTask`：カード1枚を、指定した列の、指定したカードのすぐ下に移す（ドラッグ用）、`reorderTasks`：列の中で、送ったカードどうしの番号を入れ替える（自動並び替え用）、`exportTasks`：全部のタスクを JSON のファイルとして保存させる（返事を Blob にし、見えない `<a download>` をクリックする。ファイル名は `Content-Disposition` から取る）、`importTasks`：選ばれたファイルの中身をそのまま送り、全部のタスクを置き換える）。どの関数も共通の `request` を通り、失敗したら `ApiError`（status と、バックエンドが返した ProblemDetail の中身）を投げる。通信できない、または ProblemDetail でない返事（Vite のプロキシの 502 など）は「つながらない」（status 0）として扱う。`request` と `jsonHeaders` は columnApi.ts も使う |
| `src/api/columnApi.ts` | 列の API を呼ぶ関数（`fetchColumns`：列の一覧の取得、`createColumn`：POST で列を右端に足す、`deleteColumn`：DELETE で列を消す） |
| `src/components/AddColumnForm.tsx` | ボードの右端の「＋ 列を追加」。押すと名前の欄が開き、Enter か「列を追加」で足す（名前が空欄なら何もしない。足したあとも開いたまま。✕ か Esc キーで閉じる） |
| `src/components/AddTaskForm.tsx` | タスク追加フォーム。ふだんは「＋ カードを追加」だけを出し、押すと開く（タスク名（255文字まで）・優先度（既定は中）・期限日。タスク名が空欄なら何もしない。追加後も開いたまま。✕ か Esc キーで閉じる） |
| `src/components/DataButtons.tsx` | 見出しの右の「⬇ 書き出す」「⬆ 読み込む」のボタン。読み込むは、画面に出さないファイル選び（`<input type="file">`）を `useRef` でクリックして開き、選ばれたら確認のダイアログを出して、OK のときだけ App に読み込みを頼む（同じファイルをもう一度選べるように、選んだ値は空に戻す） |
| `src/components/SearchBar.tsx` | 検索欄。キーワード・優先度（高・中・低のチェックボックス）・期限（すべて／期限切れ／7日以内／期限なしのセレクト）を選び、検索ボタンか Enter キーで、3つの条件をまとめて App に伝える。検索・絞り込み中は「✕ 検索を解除」を出し、押すと全部の条件を空に戻す |
| `src/components/Board.tsx` | App から受け取った列を左から並べ、タスクを columnId ごとに分けて、列の中を sortOrder 順に並べる。完了の列（done が true）の番号を調べてカードに渡す。一番右に「＋ 列を追加」を置く。ドラッグ＆ドロップ全体（dnd-kit の `DndContext`）を受け持ち、ドラッグ中は仮の一覧で着地点を見せる（別の列に来たら、重なったカードとそのすぐ上のカードの真ん中の番号で、仮に差し込む） |
| `src/components/Column.tsx` | 1列分（見出し・並び替えセレクト・列の削除 × ・カードのリスト・追加フォーム）。並び替えセレクトで優先度順・期限が近い順を選ぶと、その列を一度だけ並べ直す（検索・絞り込み中は、見えているカードだけを並べ直す）。× は確認のダイアログを出してから削除を頼む（基本の列（fixed が true）には出さない。列にマウスが乗っているか、列の中にフォーカスがあるときだけ見せる。Tailwind の名前付きグループ `group/column` と `group-hover/column:`・`group-focus-within/column:` を使い、`opacity` で隠すので見出しの並びはずれない）。列の中で並び替えられるようにし、空の列にもカードを落とせるようにする。ドラッグの置き場所の id は `column-1` のような文字にする（カードの id と列の番号は、どちらも数字なのでぶつかるため） |
| `src/components/TaskCard.tsx` | カード1枚（タスク名・優先度・期限）。○ で完了の列へ移す（完了の列のカードには出さない）、✎ でクイック編集（画面を暗くし、横に優先度・期限のメニュー。編集画面は `createPortal` で body の直下に出し、編集中はスクロールや画面の大きさの変化のたびにカードの位置を測り直して、元のカードにくっついて動く）、× で削除（確認のダイアログを出し、OK のときだけ削除する）。編集欄のタスク名は255文字まで。ドラッグでつかめる（キーボードでは、カードにフォーカスして Space）。○・✎・× でキーを押したときはカードに伝えず、ドラッグにならないようにしている。ドラッグ中にマウスに付いてくる分身（`TaskCardOverlay`）もここにある |
