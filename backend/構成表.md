# バックエンド構成表

## バージョン情報

| 項目 | バージョン |
| --- | --- |
| Java | 21（Eclipse Temurin 21.0.12.1、LTS） |
| Spring Boot | 4.1.1 |
| Gradle | 9.7.1（`gradlew`ラッパー経由） |
| PostgreSQL | 17.11 |

## プロジェクト構成

| ファイル・フォルダ | 役割 |
| --- | --- |
| `build.gradle` | ビルド定義。使用するSpring Bootのバージョン・依存ライブラリ（Web, Data JPA, PostgreSQLドライバ等）を記述 |
| `settings.gradle` | プロジェクト名（`backend`）の定義 |
| `gradlew` / `gradlew.bat` | Gradle本体を別途インストールしなくてもビルド・起動できるようにするラッパースクリプト（Mac/Linux用・Windows用） |
| `gradle/wrapper/` | ラッパーが使うGradle本体（`gradle-wrapper.jar`）とバージョン指定（`gradle-wrapper.properties`） |
| `.gitignore` / `.gitattributes` | Gitで無視するファイル（ビルド成果物等）・改行コード等の設定 |
| `src/main/java/.../BackendApplication.java` | アプリの起動エントリポイント（`main`メソッド） |
| `src/main/java/.../task/Task.java` | タスク1件を表すエンティティ（DBの`tasks`テーブルに対応） |
| `src/main/java/.../task/TaskRepository.java` | DBへのCRUD操作を行うインターフェース（Spring Data JPA） |
| `src/main/java/.../task/TaskController.java` | REST APIのエンドポイント定義（`/api/tasks`配下） |
| `src/main/java/.../task/TaskRequest.java` | タスク作成・更新時のリクエストボディの型 |
| `src/main/java/.../task/ReorderRequest.java` | 並び替えAPIのリクエストボディの型 |
| `src/main/resources/application.properties` | 設定ファイル（ポート番号、DB接続情報など） |
| `src/test/java/.../BackendApplicationTests.java` | 起動確認用の基本テスト |

## 実行時の設定値（`application.properties`）

| 項目 | 値 |
| --- | --- |
| アプリ名 | backend |
| ポート番号 | 8080 |
| DB接続先 | `jdbc:postgresql://localhost:5432/taskdb` |
| DBユーザー | postgres |
| DBパスワード | postgres（仮設定、要変更） |

## 提供しているREST APIエンドポイント

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | /api/tasks | 全タスク取得 |
| POST | /api/tasks | タスク作成 |
| PUT | /api/tasks/{id} | タスク更新 |
| DELETE | /api/tasks/{id} | タスク削除 |
| PUT | /api/tasks/reorder | 並び替え（一括更新） |
